# 规则索引

规则按主题拆分，执行前按需读取；本文件只做索引。

## 核心规则

| 文件 | 内容 |
| --- | --- |
| `context.md` | 单一事实源、产物即上下文、事实优先、多步骤计划、每步对账、唯一待办 |
| `decision.md` | 决策分级、断点、默认推进 |
| `initiative.md` | 主动推荐更优解、推荐不越权、基于事实、合并决策 |
| `requirement.md` | 示例非规格、目的先于手段、问题先于清单、非目标显式、发散有界 |
| `safety.md` | 不可逆操作先确认、凭据不入库、删除可恢复、最小权限 |

## 主题规则

| 文件 | 内容 |
| --- | --- |
| `collaboration.md` | 变更可审查、契约先行、决策留痕、协作交接 |
| `design.md` | 重复再抽取、抽象有界、职责单一、依赖单向 |
| `documentation.md` | 文档分型、目录命名、与代码同版本、标题与代码块规范 |
| `engineering.md` | 格式化、静态检查、类型检查、依赖锁定、本地与 CI 一致 |
| `observability.md` | 关键路径可观测、告警可行动、成本可见、日志不含敏感信息 |
| `testing.md` | 验证行为、缺陷先失败、独立可重复、质量门以命令为准 |
| `vcs.md` | 原子提交、提交信息规范、提交前检查、授权、分支策略与任务分支隔离 |
| `library.md` | 公共接口稳定、依赖最小、错误可处理、文档即契约 |
